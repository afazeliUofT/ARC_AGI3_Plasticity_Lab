You are writing an executable world model of an unknown grid game from a recorded
history of actions and the observations that followed them. The history is complete
and exact; your program must reproduce EVERY recorded transition exactly (every grid
cell, the state string and levels_completed) when replayed from the start, or it will
be rejected with a counterexample. Prefer the simplest rule that explains all of the
data. Return a single Python program implementing the contract below, in one fenced
```python block, with no other code blocks.

Level-completion conjecture (required). In the recorded history levels_completed has
never changed, so the data cannot show what completes a level. What completes the
current level is therefore a hypothesis that your program must state and implement;
a planner will search your model for the shortest action sequence that raises
levels_completed, execute that sequence on the real game, and reject your program
with a counterexample if the game disagrees. Begin your program with one comment line
starting with "# GOAL:" that states, in one sentence, the concrete condition under
which you conjecture the current level is completed (for example a movable object
reaching a marked target cell, two regions matching in colour, a counter of cells
reaching a value). Implement exactly that condition in predict(): when the frame the
action produces satisfies it, return levels_completed increased by one and the state
string "WIN" if you believe that level was the last one, otherwise "NOT_FINISHED";
when it does not, return levels_completed unchanged. The condition must hold on NO
recorded transition, or the replay check will reject the program. A program whose
levels_completed can never increase does not answer this task. Choose the simplest
conjecture consistent with the observed dynamics; when a counterexample below refutes
an earlier conjecture, state a different one rather than a variant that cannot fire.

## Program contract

A candidate program is a Python source file defining, at module level:

    def predict(history: list[dict], action: dict) -> dict

history[0] is the reset observation and history[i] (i >= 1) the observation after the i-th
recorded action. Every record is {"action": {"action": int, "data": {..}} | None,
"frame": list[list[list[int]]], "state": str, "levels_completed": int,
"available_actions": list[int]}; history[0]["action"] is None. ``action`` is
{"action": int, "data": {"x": int, "y": int} or {}}. The return value is
{"frame": list[list[list[int]]], "state": str, "levels_completed": int,
"available_actions": list[int]}: the observation the program expects after ``action``.
The program must be a pure function of its arguments; it runs in a sandbox with no network,
no repository writes and the limits given in preregistration/G3.yaml thresholds.
